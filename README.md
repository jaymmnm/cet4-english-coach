# CET-4 English Coach

一个不需要账号、服务器或数据库的个人 CET-4 英语学习工作台。学习进度只保存于浏览器；使用“导出学习数据”即可备份或迁移到另一台设备。

## 本地运行

直接双击打开 `index.html` 即可使用。若要更接近正式网站的运行方式，可在项目目录用任意静态网站预览工具打开它。

## 部署到互联网（GitHub Pages）

1. 在 GitHub 新建一个空仓库，例如 `cet4-english-coach`。
2. 上传本项目根目录中的 `index.html`、`styles.css`、`app.js` 和 `README.md`。
3. 在仓库的 **Settings → Pages** 中，选择从 `main` 分支的根目录部署并保存。
4. 等待 GitHub 显示网站地址；通常形如 `https://你的用户名.github.io/cet4-english-coach/`。

> GitHub Pages 只托管网站文件，不会保存你的学习数据。学习数据仍在每台设备自己的浏览器中；换设备前请先导出 JSON，换设备后再导入。

## 第一版范围

- 首页：每日学习清单与周学习节奏
- 词汇：翻卡、朗读、熟练度和待复习清单
- 阅读：短文、两道理解题和文章朗读
- 听力：使用浏览器的朗读功能和可调语速
- 我的：TXT/Markdown 学习材料导入、JSON 备份与恢复

PDF 导入和云端同步属于后续可扩展功能，第一版暂不包含。
